# Figure height for negative control histograms

Figure height for negative control histograms

## Usage

``` r
negative_control_plot_height(
  n_controls,
  ncol_layout = 3,
  base_height_per_row = 2.5,
  min_height = 6,
  max_height = 20
)
```

## Arguments

- n_controls:

  Number of negative controls plotted.

- ncol_layout:

  Number of facet columns.

- base_height_per_row:

  Height per row of facets, in inches.

- min_height, max_height:

  Height limits, in inches.

## Value

Figure height in inches.
