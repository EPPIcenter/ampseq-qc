# ampseqQC: Quality Control Reports for Mad4hatter Amplicon Sequencing Runs

Summarises quality control statistics for targeted amplicon sequencing
runs processed with the Mad4hatter pipeline, combining pipeline outputs
with a sample manifest. Provides functions to load results, assign
targets to multiplex PCR reactions from their pools, classify samples as
pass, repool or reprep, summarise positive and negative controls, filter
allele tables, and render an HTML QC report.
