# Negative control amplicon coverage

Negative control amplicon coverage

## Usage

``` r
negative_control_amplicons(amplicon_coverage_with_manifest)
```

## Arguments

- amplicon_coverage_with_manifest:

  Output of
  [`merge_amplicon_coverage()`](https://eppicenter.github.io/ampseq-qc/preview/pr-21/reference/merge_amplicon_coverage.md).

## Value

Amplicon coverage for negative controls, with a `negative` label giving
the batch and well.
