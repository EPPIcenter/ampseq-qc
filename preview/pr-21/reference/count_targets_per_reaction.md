# Count targets per reaction

Count targets per reaction

## Usage

``` r
count_targets_per_reaction(panel_reactions)
```

## Arguments

- panel_reactions:

  Panel information with reactions, from
  [`assign_reactions()`](https://eppicenter.github.io/ampseq-qc/preview/pr-21/reference/assign_reactions.md).

## Value

A data frame with `reaction` and `nreactionloci`.
