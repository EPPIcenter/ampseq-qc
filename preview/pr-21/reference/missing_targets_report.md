# Targets in the panel missing from the allele data

Targets in the panel missing from the allele data

## Usage

``` r
missing_targets_report(panel_information, allele_data)
```

## Arguments

- panel_information:

  Panel information from Mad4hatter.

- allele_data:

  Allele data from Mad4hatter.

## Value

`target_name`, `pool` and `chrom` of targets with no allele data.
