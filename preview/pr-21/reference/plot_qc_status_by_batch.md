# QC status by batch

QC status by batch

## Usage

``` r
plot_qc_status_by_batch(qc_summary_by_batch)
```

## Arguments

- qc_summary_by_batch:

  Output of
  [`qc_summary_by_batch()`](https://eppicenter.github.io/ampseq-qc/preview/pr-21/reference/qc_summary_by_batch.md).

## Value

A stacked bar chart of the percentage of samples in each status.
